### Game Development

Before Fontys, I had no experience with game development. The Witness is the first game I am making, and I am learning Godot as I go. It is a 2D top-down stealth game with a noir style inspired by Sin City. In the game, a witness sees a murder by gangsters and must escape without being seen.

At first, I wanted to use realistic top-down sprites for the characters, but that turned out to be too difficult and I got stuck. So I changed my approach. I used Mixamo mannequin animations in Blender, placed a camera above them, and took frames from the animations. This created the faceless mannequin style the game has now. My coach advised me to document this problem and the change instead of hiding it. This was an important lesson for me: when a plan does not work, I can try a different way instead of giving up.
